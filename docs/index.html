Daily price trackers

Daily snapshots of public language-model API prices and GPU rental prices, with a dated record of every change.

A list price can be looked up at any time, but what it was last month cannot be looked up afterwards unless someone wrote it down. These pages write it down once a day.

LiteLLM and models.dev are MIT-licensed projects; their price lists are reused here with attribution. Azure prices come from the Azure Retail Prices API, which Microsoft documents as open to unauthenticated use. Verda prices come from its public instance-types endpoint. The compiled data on this site is published under CC BY 4.0 and the code under the MIT licence. The copyright and permission notices of the two MIT-licensed lists are in NOTICE.txt.

Provider and model names are shown as the source lists give them. The lists cover resellers and aggregators as well as first-party providers, and a value that looks implausible is shown as the source lists it.

This site is produced by an automated pipeline run by one person with AI agents. Nothing is edited by hand. Check the provider's own price page before relying on a number.
